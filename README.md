#JavaScript Fundamentos 03

Constinuação do JavaScript com foco em funçôes, métodos de arrays, objetos, JSON e introdução á Programação.


## Objetivos

- Criar e utilizar funções;
- Trabalhar com parâmetros, argumentos e retornos;
- Utilizar arrow functions;
- Criar e manipular objetos;
- Trabalahar com arrays de objetos;
- Entender o uso de `This`;
- Converter objetos para JSON e JSON para objetos;
- Criar classes
- Utilizar `constructor`;
- Instanciar objetos com `new`;
- Criar atributos e métodos;
- Compreender os conceitos indiciais de encapsulamento, herança e polimorfismo;

## Como executar

Exemplo:
Abra o terminal na pasta do projeto 

```Bash
node 01-funcoes/01-funcao-simples.js
```
